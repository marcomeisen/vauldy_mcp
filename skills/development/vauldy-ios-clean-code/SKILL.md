# Vauldy – bisheriger Skillname

Die Vauldy-App gehört nicht mehr zum aktuellen Entwicklungsumfang. Die Dokumentinteraktion
erfolgt über einen Chatbot, lokale Einrichtung und Freigaben über die vorhandenen MCP-Programme.

Für aktuelle Architektur-, Swift-, Persistenz-, Setup- und Releasearbeit
[vauldy-mcp-development](../vauldy-mcp-development/SKILL.md) verwenden.
Für Suche/Evidenz [vauldy-ai-search-assistant](../vauldy-ai-search-assistant/SKILL.md), für Import/OCR
[vauldy-import-ocr-sync](../vauldy-import-ocr-sync/SKILL.md) verwenden.

Dieser Verweis erhält bestehende explizite Aufrufe. Er führt keine iOS- oder Legacy-App-Anweisungen
in MCP-Aufgaben ein. Das aktuelle Repository und dessen `AGENTS.md` sind maßgeblich.
