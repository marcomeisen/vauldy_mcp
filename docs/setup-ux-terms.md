# Begriffe in der Vauldy-Einrichtung

Die Einrichtung heißt im Fenster **Vauldy**. „Vauldy MCP Einrichtung“ bleibt der technische Name des Installationspakets und ausführbaren Programms.

| Begriff im Hauptablauf | Bedeutung | Technischer Begriff nur in Diagnose und Dokumentation |
| --- | --- | --- |
| Dokumentbestand | Die auf diesem Mac verwalteten Dokumente und ihre gespeicherten Angaben | JSON-Bestand, SQLite-Datenbank, Vault |
| Chatbot-Verbindung | Ein eingerichteter Chatbot mit eigenem Zugriff | MCP-Client, Client-Eintrag, OAuth-Verbindung |
| Dokumentauswahl | Die konkreten Dokumente, die ein Chatbot lesen darf | Grant, Profil, Allowlist |
| Fundstelle | Ein wörtlicher Beleg auf einer physischen Dokumentseite | Evidence, Source Reference |
| Prüfhinweis | Ein konkreter Grund, Text oder Original vor einer Freigabe anzusehen | Review-Issue |
| Textprüfung | Die Ansicht zum Vergleich von Original und gespeichertem Text | OCR-Review |
| Empfänger im Dokument | Eine aus dem Dokument gelesene Feldrolle | Recipient |
| Kennung des Dienstes | Diagnosewert für den tatsächlich gebauten oder installierten Dienst | Build-ID |

Anleitungen und Schaltflächen verwenden die Begriffe links. Technische Formate und Kennungen erscheinen nur dort, wo sie für Diagnose, Import eines fremden Bestands oder Betrieb nötig sind. Anzahl und Bezugswort werden gemeinsam formuliert, etwa „1 Dokument“ und „2 Dokumente“.
